# CSCD327_Relational_Databases
Implementations of SQL and Relational Databases through coursework of CSCD 327 Relational Databases

## Labs: 

### Lab 2:
Built a PostgreSQL database for a gym that tracks instructors, classes, members, and bookings. Covers primary and foreign keys, a join table for a many-to-many relationship, changing tables with ALTER TABLE, and adding a CHECK constraint to a table that already had invalid data using NOT VALID and VALIDATE CONSTRAINT.

### Lab 3: 
PostgreSQL lab on core query skills using a bookstore database. It covers calculated columns, DISTINCT, filtering with BETWEEN, IN, LIKE/ILIKE, and AND/OR precedence, NULL handling with IS NULL and COALESCE, sorting, and set operations (UNION, INTERSECT, EXCEPT).

### Lab 4: 
PostgreSQL lab on table joins using a music store database (products, categories, customers, orders). It covers INNER, LEFT, and RIGHT joins, multi-table joins, finding unmatched rows with IS NULL, and fixing common join mistakes such as ambiguous columns, wrong join keys, and NATURAL JOIN pitfalls.

### Lab 5: 
PostgreSQL practice with aggregate functions, GROUP BY/HAVING, NULL handling, and joins on a books database, including fixes for common query errors.

### Lab 6: 
Relational algebra and SQL side by side on the university schema, covering selection, projection, joins, rename, set operations, division, and query trees.
